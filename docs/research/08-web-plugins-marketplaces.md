# Prior art: Claude/Codex plugins & marketplaces for Godot game dev (web research, 2026-11-12)

Saved verbatim-in-substance from the pipeline-web-researcher hand-back (agent had no write tools).

## Executive summary

- Many Godot skill packs and several Godot MCP servers exist; no official Godot plugin from Anthropic or the Godot project. Unity and Epic both ship official Claude Code plugins.
- Strongest prior art: GodotPrompter (59 skills, 9 agents, CI-validated examples, multi-host), MindsMaster/godot-claude-code-skills (every example run on Godot 4.7.2 in CI), iboss-ptk/godot-claude-plugin (PostToolUse gdlint + `godot --check-only` hooks), godogen and Claude-Code-Game-Studios (runtime-verified pipelines / studio hierarchies).
- Gap: nobody combines enforced verification hooks + runtime loop (screenshots + input) + small context cost + Claude/Codex packaging in one Godot marketplace.

## Patterns worth copying

1. Enforced verification hooks (PostToolUse gdlint + check-only); SessionStart routing; PreToolUse guard against visible editor windows.
1. Skills tested as code: snippets run on pinned Godot in CI, API names vs class ref, SKILL.md size cap, evals with/without plugin.
1. Knowledge (skills) vs actions (MCP) separation; lazy meta-tools.
1. Judge the running game: screenshots/video + simulated input; session-only bridge injection.
1. Context cost as a constraint: project-scope install, small hub + lazy domain skills + index.
1. Multi-host from one repo: .claude-plugin/, .codex-plugin/, .agents/plugins/marketplace.json sharing one skills/ tree; Codex replaces hooks with validator scripts.
1. Studio gates: tiered escalation, no self-approval, human-only milestone gates, parallel worktree lanes.
1. Builtin-first entry skill; addon-specific skills.
1. Scene source of truth: build scripts generate .tscn.

## Gaps

1. No official/reference Godot marketplace (High).
1. Enforced verification + runtime loop in one Godot plugin (High).
1. Godot-native studio roles: scene/node architect, .tscn/resource integrity reviewer, GdUnit4/GUT test author, export/release agent (High).
1. .tscn/.tres/UID integrity checks (Med).
1. Version awareness from project.godot config/features (Med).
1. Godot-tuned design/playtest/balance agents (Med).
1. In-Godot asset pipeline: import presets, atlases, audio buses, Blender handoff (Med).
1. Codex parity (High).
1. Security posture for editor MCPs (Med).
