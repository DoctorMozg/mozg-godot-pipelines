# Writing Godot shaders (Godot 4.7)

Source: web research of 2026-11-13 against docs.godotengine.org (4.7 and latest pages) and the 4.4/4.5 release notes. Claims marked UNVERIFIED are not confirmed by a primary source; none of it has been run on 4.7.2 yet.

## Executive Summary

Fast, portable Godot 4.7 shaders are opaque where possible (use alpha scissor or hash, not alpha blending). They make few texture reads, and they declare screen, depth and normal reads as hinted sampler uniforms instead of the 3.x built-ins. They use `source_color` on every color uniform and texture, and they branch at compile time with `#if CURRENT_RENDERER` (4.4+) when a feature does not exist on a renderer. Since 4.4, Forward+ and Mobile precompile pipelines through ubershaders, and since 4.5 the export-time shader baker cuts startup time. Compatibility gets neither, so it still needs manual warm-up (draw each material once behind a loading screen), and so does 2D on every renderer. For maintainability, use one `.gdshader` per material family, share code in `.gdshaderinc` files, and keep text shaders (they diff in git) over visual shaders. Give per-object variation through `instance uniform`, not duplicated materials.

A minimal spatial shader in the official style guide order, using a renderer branch:

```glsl
shader_type spatial;
render_mode cull_back, diffuse_burley, specular_schlick_ggx;
#include "res://shaders/lib/noise.gdshaderinc"

group_uniforms surface;
uniform sampler2D albedo_tex : source_color, filter_linear_mipmap_anisotropic, repeat_enable;
uniform vec4 tint : source_color = vec4(1.0);
uniform float roughness : hint_range(0.0, 1.0) = 0.8;
group_uniforms;
instance uniform float hue_shift = 0.0;

void fragment() {
	vec3 c = texture(albedo_tex, UV).rgb * tint.rgb;
#if CURRENT_RENDERER == RENDERER_COMPATIBILITY
	c = c; // cheap path: skip the extra noise fetch on GLES3
#else
	c *= 0.9 + 0.1 * noise2(UV * 8.0);
#endif
	ALBEDO = c;
	ROUGHNESS = roughness;
}
```

The style guide sets this order: shader_type, render_mode, docstring, uniforms, constants, varyings, functions, `vertex`, `fragment`, `light`. It also asks for tabs, snake_case names, CONSTANT_CASE constants and macros, floats written as `1.0` (not `1.`), `rgba` swizzles for colours and `xyzw` otherwise, braces always, lines of at most 100 characters, and `/** */` doc comments on uniforms, which show as inspector tooltips. Source: [shaders_style_guide](https://docs.godotengine.org/en/latest/tutorials/shaders/shaders_style_guide.html) (high confidence).

How to warm up shaders:

- Render an off-screen "warm-up" scene, for example under a ColorRect or in a SubViewport, during loading.
- Keep hidden instances of dynamically spawned VFX parented to a persistent node.
- Apply graphics-settings changes behind a loading screen.

Before and after: per-object tint.

```gdscript
# Before: one unique material per enemy breaks batching and grows memory.
mesh.material_override = base_mat.duplicate()
mesh.material_override.set_shader_parameter("tint", c)
# After: shared material plus an `instance uniform vec4 tint : source_color;`.
mesh.set_instance_shader_parameter(&"tint", c)
```

### 6. Pitfalls

| Anti-pattern                                                                              | Fix                                                                                                                                                                                                                                                                  | Source                        |
| ----------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- |
| A colour uniform or albedo texture without `source_color`                                 | Add it. It looks fine on Compatibility and washed out on Forward+ and Mobile.                                                                                                                                                                                        | shading_language 4.7          |
| Unbounded `sin(TIME * k)` effects                                                         | `TIME` wraps at 3600 s by default (`rendering/limits/time/time_rollover_secs`), which makes effects jump. It follows `time_scale` and ignores pause. For precision over long sessions, use periods that divide the rollover, or a global uniform driven from script. | spatial_shader 4.7            |
| 3.x `SCREEN_TEXTURE`, `DEPTH_TEXTURE`, `hint_color`, `.shader` files, particle `vertex()` | Hinted sampler uniforms, `source_color`, `.gdshader`, `start()`/`process()`                                                                                                                                                                                          | upgrading_to_godot_4          |
| Depth maths written before 4.3                                                            | Account for reverse-Z on RD renderers, and branch on `CURRENT_RENDERER`.                                                                                                                                                                                             | upgrading_to_godot_4          |
| `material.duplicate()` per frame or per spawn                                             | Use instance uniforms or global uniforms. Duplicate once at most, or set `resource_local_to_scene`.                                                                                                                                                                  | ShaderMaterial / Resource 4.7 |
| Many unique 2D materials, or Z index and layer interleaving                               | Share materials and use canvas instance uniforms (4.4+).                                                                                                                                                                                                             | 4.4 release; gpu_optimization |
| Writing `ALPHA` "just in case", including in `light()`                                    | It forces the transparent pipeline. Use `ALPHA_SCISSOR_THRESHOLD` or opaque.                                                                                                                                                                                         | spatial_shader 4.7            |
| `DEPTH` written in some branches only                                                     | Write it in all branches.                                                                                                                                                                                                                                            | spatial_shader 4.7            |
| Out-of-range array index, infinite loop, float `==`                                       | Clamp indices, bound loops, compare with an epsilon.                                                                                                                                                                                                                 | shading_language              |
| Reading `global_shader_parameter_get` every frame                                         | Keep the value in script.                                                                                                                                                                                                                                            | shading_language 4.7          |
| `hint_normal_roughness_texture` or compute on Mobile/Compatibility                        | Gate with `#if CURRENT_RENDERER == RENDERER_FORWARD_PLUS` and provide a fallback.                                                                                                                                                                                    | renderers; preprocessor       |

## Trend Analysis

- Stutter work is moving to the engine. 4.4 brought ubershaders, 4.5 the shader baker, and 4.5 FP16 on Mobile. Compatibility and 2D are the remaining gaps (as of the 4.7 docs).
- Per-instance data is replacing material duplication: canvas instance uniforms arrived in 4.4.
- Renderer-aware shaders are now first-class through the 4.4 `CURRENT_RENDERER` defines. Stencil (4.5) is still experimental.

## Checkable rules for agents writing Godot shaders

1. Store each shader as a `.gdshader` file (never embedded in `.tscn`). Shared code goes in `.gdshaderinc` through `#include`.
1. File order follows the style guide: shader_type, render_mode, uniforms, const, varyings, functions, vertex, fragment, light. Tabs, snake_case, CONSTANT_CASE macros, `1.0`-style floats.
1. Every colour `vec3`/`vec4` uniform and every albedo or emission `sampler2D` carries `source_color`.
1. Every `sampler2D` uniform declares an explicit `filter_*` and `repeat_*` hint. A `_mipmap` filter is used only when the texture imports with mipmaps.
1. Never use `SCREEN_TEXTURE`, `DEPTH_TEXTURE`, `NORMAL_ROUGHNESS_TEXTURE`, `hint_color`, `hint_albedo` or `.shader` (grep for them).
1. `hint_normal_roughness_texture`, compute, fog shaders and other Forward+-only features sit behind `#if CURRENT_RENDERER == RENDERER_FORWARD_PLUS`, with a fallback.
1. Write `ALPHA` only when partial transparency is required. Otherwise use opaque, `ALPHA_SCISSOR_THRESHOLD` or alpha hash.
1. If `DEPTH` is written, write it on every code path.
1. Write no `discard` in a shader that could use alpha scissor. Each remaining `discard` gets a one-line why-comment.
1. The number of texture fetches per fragment is stated in the shader's doc comment. Channel-packed maps are preferred over separate greyscale maps.
1. Compute per-object or per-vertex values in `vertex()` and pass them through varyings. No varying is assigned outside `vertex()`/`fragment()`.
1. Feature toggles fixed at authoring time use `#define`/`#if`, not runtime `if` on a uniform.
1. Every `TIME`-driven effect is either periodic with a period that divides 3600 s, or reads a script-driven global uniform.
1. Per-object variation uses `instance uniform`, with at most 16 per shader and only scalars or vectors. Never use `duplicate()` per spawn or per frame.
1. World-wide values (wind, time of day, player position) are global uniforms registered in Project Settings > Shader Globals. Never read them back with `global_shader_parameter_get` in a loop.
1. GDScript sets parameters with `StringName` names that match the uniform exactly, and with type-matched values (float for float, `Color` or `Vector4` for vec4).
1. Use `StandardMaterial3D`/`CanvasItemMaterial` unless the shader needs logic they cannot express. The reason goes in the shader's doc comment.
1. Visual shaders are allowed only for artist-owned materials. Engineering shaders are text.
1. Every new material is added to the loading-screen warm-up scene, which must be drawn in the frustum at least one frame. This is mandatory for Compatibility and for 2D.
1. Export presets for Forward+/Mobile enable Shader Baker > Enabled (4.5+) on non-web, non-headless exports.
1. Check the debugger pipeline-compilation monitors after a playthrough: no growth outside loading screens, and zero in the "Surface" step.
1. Transparent 3D materials set `render_priority` deliberately when they overlap, and `next_pass` chains are ordered with it.
1. Hand-written depth maths are tested on both an RD renderer (reverse-Z, NDC z 0..1) and Compatibility.
1. Uniform arrays and large tables stay under 16 KB on mobile (padding counted). Larger data goes into a texture.
1. Mobile and Compatibility shaders assume at most 8 lights per mesh, and do not depend on `light()` running when vertex shading is forced.
